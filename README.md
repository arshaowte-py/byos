# Frido · Make Your Own Shoe

Store portal for Frido's scientifically personalised footwear. Single self-contained `index.html`, live at https://fridoxbyos.netlify.app.

- No build step: Netlify publishes the repo root (`netlify.toml`).
- Run locally: `npx serve .` (or any static server) and open the printed URL.
- Project notes, flow, business logic and ground rules: see `CLAUDE.md`.
